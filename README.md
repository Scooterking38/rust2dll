# rust2dll
A Rust-based library to create Windows DLLs using the `windows-sys` crate.

## Features
* Converts Rust code into a Windows Dynamic Link Library (DLL) using the `cdylib` crate type.
* Utilizes the `windows-sys` crate to provide low-level system programming functionality.

## Tech Stack
* Rust 2021
* `windows-sys` crate (version 0.52)
* `cdylib` crate

## Installation
1. Add the following line to your `Cargo.toml` file:
```toml
[dependencies]
rust2dll = "0.1.0"
```
2. Run the command `cargo build` in your terminal to build and compile the library.
